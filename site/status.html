Objetivo de latencia

Reporte v1 publicado en ≤ 60 min (p50) y ≤ 90 min (p95) desde que el primer ShakeMap del evento esta disponible.

El cron de GitHub Actions es best-effort: sus demoras documentadas van de 5 a 30 minutos y no las controlamos. El objetivo se define sobre lo que si controlamos, y la demora real del cron se publica aparte para que se pueda auditar la diferencia.
